# Сельскохозяйственный симулятор на JS (ООП, модули)

## Запуск локально
1. Склонируйте репозиторий или скачайте файлы проекта.
2. Откройте index.html в современном браузере (Chrome/Edge/Firefox).
3. Никаких сборок не требуется — используются нативные ES-модули.

## Структура проекта
- index.html — основной HTML-документ.
- css/style.css — стили для сетки, растений и интерфейса.
- js/main.js — точка входа, инициализация игры.
- js/modules/ — директория с модулями:
  - Cell.js — базовый класс клетки:
    - Land — земля, имеет свойство влажности.
    - Water — вода, всегда 100% влажность, влияет на соседние клетки.
  - Plant.js — базовый класс растения:
    - MarshPlant — болотник, требует высокой влажности.
    - Potato — картошка, требует средней влажности.
    - Cactus — кактус, требует низкой влажности.
    - Каждое растение имеет стадии роста, визуализируемые с помощью emoji.
  - Game.js — основной класс игры:
    - создание сетки клеток;
    - обработка событий (инструменты, клики);
    - обновление состояния (рост растений, влажность);
    - визуализация информации о клетке.

## Как играть
- Лопата — меняет тип клетки (земля/вода).
- Ведро — увеличивает влажность клетки на 20%.
- Семена — позволяют посадить растение на землю.
- Растения растут при подходящей влажности на каждом ходе ("Следующий ход"), иначе погибают.
- Влажность земли зависит от близости к воде и уменьшается со временем.

## Визуализация
- Цвет земли: от жёлтого (сухая) до тёмно-коричневого (влажная).
- Растения: отображаются emoji, меняющиеся по стадиям роста.
- Вода: отображается синим цветом.

## Требования к влажности растений
- Болотник: влажность > 70%
- Картошка: влажность 30–70%
- Кактус: влажность < 30%
