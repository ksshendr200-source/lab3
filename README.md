Сельскохозяйственный симулятор
Веб-приложение, реализующее простой сельскохозяйственный симулятор, написанный на JavaScript с использованием ООП и модулей.

Описание
Симулятор позволяет управлять фермой: создавать участки земли и воды, сажать различные растения и управлять влажностью почвы. Растения имеют разные предпочтения по влажности и проходят несколько стадий роста.

Как запустить
Склонируйте репозиторий или скачайте файлы проекта.

Откройте файл index.html в современном браузере (Chrome, Edge, Firefox).

Никаких дополнительных сборок не требуется, так как используются нативные ES-модули.

Структура проекта
index.html - основной HTML-документ.

css/style.css - стили для внешнего вида сетки, растений и интерфейса.

js/main.js - точка входа, инициализация игры.

js/modules/ - директория с модулями:

Cell.js - базовый класс клетки и его наследники (Земля, Вода).

Plant.js - базовый класс растения и его наследники (Болотник, Картошка, Кактус).

Game.js - основной класс игры, управляющий сеткой, инструментами и игровым циклом.

Модули
Cell.js
Содержит класс Cell — базовый для всех клеток. От него унаследованы:

Land — класс земли, имеет свойство влажности, которое влияет на цвет.

Water — класс воды, всегда имеет 100% влажность и влияет на соседние клетки.

Plant.js
Содержит класс Plant — базовый для всех растений. От него унаследованы:

MarshPlant — болотник, требует высокой влажности.

Potato — картошка, требует средней влажности.

Cactus — кактус, требует низкой влажности.

Каждое растение имеет стадии роста, которые визуализируются с помощью emoji.

Game.js
Класс Game управляет:

Созданием сетки клеток.

Обработкой событий (выбор инструмента, клики по клеткам).

Обновлением состояния игры (рост растений, изменение влажности).

Визуализацией информации о выбранной клетке.

Как играть
Лопата — позволяет менять тип клетки (земля/вода).

Ведро — увеличивает влажность выбранной клетки на 20%.

Семена — позволяют посадить выбранное растение на клетку земли.

После посадки растения будут расти на каждом ходе (при нажатии кнопки "Следующий ход"), если влажность подходит. В противном случае растение погибает.

Влажность земли зависит от близости к воде: клетки воды увеличивают влажность соседних клеток. Также влажность постепенно уменьшается со временем.

Визуализация
Цвет земли плавно меняется от желтого (сухая) до темно-коричневого (влажная).

Растения отображаются emoji, которые меняются в зависимости от стадии роста.

Вода отображается синим цветом.

Требования к влажности растений
Болотник: влажность >70%

Картошка: влажность от 30% до 70%

Кактус: влажность <30%

Проверка кода
Для проверки кода линтером (ESLint) и форматирования (Prettier) можно выполнить следующие команды (при наличии конфигурационных файлов):

bash
npx eslint js/modules --ext .js
npx prettier --check .
Однако, в проекте не предусмотрены конфигурации для линтеров, так как это минималистичный пример.
